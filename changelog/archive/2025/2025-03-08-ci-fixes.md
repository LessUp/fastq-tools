# 2025-03-08 CI 工作流全面修复

> 本文件合并自 4 个同日同主题的独立 changelog 条目。

## 背景

CI 工作流存在多处问题：脚本路径过时、Clang 构建缺少 libc++ 开发包、链接器找不到 libc++ 库、quality.yml 未覆盖 master 分支。

## 变更

### 1. 安装 libc++ 开发包

在 `.github/workflows/ci.yml` 的 Clang 安装步骤中添加 `libc++-21-dev` 和 `libc++abi-21-dev`，修复 Conan 构建依赖时 `-stdlib=libc++` 链接失败。

### 2. 修复 libc++ 链接器搜索路径

`libc++-21-dev` 库文件位于 `/usr/lib/llvm-21/lib/`，不在链接器默认路径。将该路径导出到 `LIBRARY_PATH` 环境变量。

### 3. Format / Static Analysis / Clang 构建修复

- 使用 clang-format-21 格式化全部源文件
- 修复 `scripts/core/lint` 中 `set -e` 导致 `run_xxx` 返回非零时脚本退出的问题
- CI LLVM 版本从 21（不稳定）降级到 20（稳定版）
- Conan clang profile 添加 `-pr:h config/conan/profile-clang`

### 4. 工作流配置修复

- `ci.yml`: 脚本路径 `scripts/build.sh` → `scripts/core/build` 等，修复 Actions 表达式语法错误
- `quality.yml`: 添加 `master` 到触发分支
- `release.yml`: 新增 `ci-gate` job，确保 CI 通过后才允许发布

## 影响

- 涉及 job：lint、build-and-test（clang 矩阵）、coverage、release
- quality.yml 首次在 master 分支上生效
