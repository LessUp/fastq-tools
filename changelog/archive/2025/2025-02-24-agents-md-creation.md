# 2025-02-24 创建 AGENTS.md 项目 AI Agent 指南

- 项目缺少标准的 `AGENTS.md` 文件，AI 编码助手需要依赖 memory 中的缓存信息来理解项目上下文。
- 需要一份基于实际代码库的、全面且准确的 Agent 指南文档。

- 在项目根目录创建 `AGENTS.md`，内容涵盖：
  - 项目概览（技术栈、语言、构建系统、许可）

  - 命名空间与子命令一览

  - Git 提交规范
  - CMake 预设说明
  - 变更记录规则
  - Agent 注意事项（7 条关键指引）
- 同步更新 Windsurf memory 缓存

## 影响
