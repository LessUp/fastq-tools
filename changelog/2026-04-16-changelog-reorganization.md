# 2026-04-16 Changelog 文档彻底重构

## 概述

对 FastQTools 项目的 changelog 文档体系进行彻底整理和重构，建立清晰的变更记录管理机制。

## 变更详情

### 1. 目录结构重组

```
changelog/
├── README.md               # 使用指南和编写规范
├── 2025-summary.md         # 2025 年度汇总
├── 2026-summary.md         # 2026 年度汇总
├── YYYY-MM-DD-<slug>.md    # 当前月份变更
└── archive/                # 历史归档
    ├── 2025/               # 2025 年详细变更（50 文件）
    └── 2026/               # 2026 年详细变更（26 文件）
```

### 2. 年度汇总文件

创建 `2025-summary.md` 和 `2026-summary.md`，按主题分类汇总：

- 架构与重构
- 构建系统
- 开发环境
- 性能与测试
- 文档
- CI/CD

### 3. CHANGELOG.md 优化

- 简化为版本摘要格式
- 添加 Unreleased 区块
- 链接到详细变更记录

### 4. 编写规范统一

在 `changelog/README.md` 中明确：

- 文件命名规范（kebab-case）
- 内容模板
- 归档规则
- 与主 CHANGELOG 的关系

## 影响范围

- 变更记录更易于查找和管理
- 年度汇总提供快速概览
- 无代码变更，不影响功能
