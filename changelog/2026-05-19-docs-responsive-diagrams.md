## 目标

修复 GitHub Pages 文档站中首页卡片过窄、系统图谱容器过小，以及架构图排版拥挤的问题。

## 主要改动

- 放宽无侧栏白皮书首页的 VitePress 内容宽度约束，让首页卡片按页面宽度自适应。
- 将首页系统图谱改为全宽图表通道，说明卡片在图表下方自适应排列，避免半宽列裁切 SVG。
- 扩大架构总览图的 SVG 画布与节点间距，提升中文与英文标签的可读性。
- 增加文档主题回归测试，覆盖首页宽度、系统图谱布局和架构图画布约束。

## 影响范围

仅影响 docs VitePress 主题样式、内联架构图组件和文档站测试，不改变 C++ 代码、公共 API 或文件格式。

## 验证方式

- `cd docs && npm test`
- `cd docs && npm run build`
- `git --no-pager diff --check`
