# 更新日志

FastQTools 的变更历史按三个层级维护，方便不同读者按需获取信息。

## 去哪里看变更

| 如果你想… | 建议查看 |
| --- | --- |
| 了解可安装版本和发布说明 | [GitHub Releases](https://github.com/LessUp/fastq-tools/releases) |
| 查看项目级别的整理版变更历史 | [CHANGELOG.md](https://github.com/LessUp/fastq-tools/blob/master/CHANGELOG.md) |
| 查看更细粒度的实现记录 | [`changelog/` 目录](https://github.com/LessUp/fastq-tools/tree/master/changelog/) |

## 建议如何阅读

- **Releases** 最适合判断是否需要升级。
- **CHANGELOG.md** 适合快速了解项目在版本层面的变化。
- **`changelog/` 下按日期命名的文件** 会记录更窄范围的工作，例如文档整理、工具链调整、仓库结构清理等。

## 为什么保留这个页面

对公共读者来说，最常见的问题是“最近改了什么、应该去哪看”。这个页面提供简洁入口，让主导航保持清晰，同时不把项目历史藏起来。
