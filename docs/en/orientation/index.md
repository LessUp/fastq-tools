## Project position

FastQTools is an engineering-focused toolkit for the FASTQ QC core, not a workflow platform for every downstream bioinformatics job.

## Reading path

2. Continue to [`Algorithms`](../algorithms/) when you want execution, filtering, and workflow guidance.
