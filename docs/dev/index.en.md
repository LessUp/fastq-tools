## Quick Start

1. Read the [Architecture](architecture.en.md) to understand the overall structure
2. Follow the [Build Guide](build.en.md) to set up your development environment
3. Review the [Coding Standards](coding-standards.en.md) for code style
4. Refer to the [Testing Strategy](testing.en.md) for writing tests

## Development Workflow

```
1. Fork the repo → 2. Create a feature branch → 3. Write code and tests → 
4. Run lint/test → 5. Submit PR → 6. Code Review → 7. Merge
```
