## 如何使用这张地图

如果你还在问“先看哪里”，从 [`导读`](../orientation/) 开始；如果你已经在问“这些主张为什么可信”，进入 [`技术白皮书`](../whitepaper/)；如果你已经知道要执行什么，再进入 [`工作流`](../workflows/) 与 [`参考导航`](../reference/)。

## 三层阅读结构

| 层级 | 主要页面 | 作用 |
| --- | --- | --- |
| 导读层 | [`导读`](../orientation/)、[`为什么选择 FastQTools`](../why-fastqtools/) | 帮助判断项目定位与阅读顺序 |
| 白皮书层 | [`技术白皮书`](../whitepaper/)、[`架构`](../architecture/)、[`性能总览`](../performance/) | 建立系统边界、执行模型与证据理解框架 |
| 执行层 | [`工作流`](../workflows/)、[`guide/`](../guide/)、[`api/`](../api/)、[`dev/`](../dev/) | 支撑命令运行、接口集成与维护实践 |

## 常见问题对应入口

- 想判断项目是否适合当前 FASTQ QC 场景：[`为什么选择 FastQTools`](../why-fastqtools/)
- 想理解白皮书主线：[`技术白皮书`](../whitepaper/)
- 想验证性能叙事与 benchmark：[`性能总览`](../performance/)
