# 资源中心

资源中心汇总的是“阅读主线之外，但在协作与研究时很重要”的入口：官方事实来源、协作入口、外部背景资料，以及帮助你理解项目语境的参考链接。

## 协作与事实来源

- [`参与贡献`](../contributing/) —— 准备提交文档、测试或代码改动时先看这里；
- [`开发者文档`](../dev/) —— 面向维护者的构建、测试与架构材料；
- [OpenSpec baseline](https://github.com/LessUp/fastq-tools/tree/master/openspec/baseline) —— 当前规范事实来源；
- [GitHub 仓库](https://github.com/LessUp/fastq-tools) —— Issue、Discussion、Release 与源码总入口。

## 研究与背景资料

- [`研究附录`](../research/) —— 站内的研究 framing、参考文献与演进思考；
- [FASTQ format（Wikipedia）](https://en.wikipedia.org/wiki/FASTQ_format) —— 复习格式背景；
- [NCBI SRA submit formats](https://www.ncbi.nlm.nih.gov/sra/docs/submitformats/) —— 理解 FASTQ 在交换语境中的位置；
- [FastQC](https://www.bioinformatics.babraham.ac.uk/projects/fastqc/) / [fastp](https://github.com/OpenGene/fastp) / [Cutadapt](https://cutadapt.readthedocs.io/en/stable/) —— 对照行业中常见 QC / trimming 语境。

## 历史与归档

- [`归档概览`](../archive/) —— 解释哪些内容已经迁移、哪些只保留参考价值；
- [GitHub Releases](https://github.com/LessUp/fastq-tools/releases) —— 查看可安装版本与配套发布说明；
- [根目录 `CHANGELOG.md`](https://github.com/LessUp/fastq-tools/blob/master/CHANGELOG.md) —— 查看当前维护中的项目级变更历史。

## 如何使用这些资源

如果你在主文档里遇到“这件事的长期承诺在哪里”“这个概念在行业里怎么说”“为什么旧文档不再更新”这类问题，资源中心通常就是最有效的下一站。
