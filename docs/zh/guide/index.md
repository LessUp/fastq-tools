# 学习指南

学习指南是学院路径中的“实操层”。它假设你已经理解 FastQTools 的定位，下一步需要把认知变成可以执行的命令、配置与部署动作。

## 建议的学习顺序

| 阶段 | 你要解决的问题 | 建议阅读 |
| --- | --- | --- |
| 第一步 | 我怎样最快跑通一次处理？ | [`快速开始`](./getting-started) |
| 第二步 | 我有哪些命令与参数可以调用？ | [`CLI 参考`](./cli-reference) |
| 第三步 | 参数、环境变量与默认值如何协同？ | [`配置说明`](./configuration) |
| 第四步 | 如何把它放进容器、CI 或批处理环境？ | [`部署指南`](./deployment) |

## 这组页面解决什么问题

- 让第一次接触项目的人能在最短路径内完成一次统计或过滤任务；
- 让已有使用者快速定位命令语法、配置优先级与部署注意事项；
- 让维护者在进入开发文档前，先掌握面向用户的实际工作流。

## 阅读方式建议

如果你只需要“今天就跑起来”，按顺序读完快速开始与 CLI 参考即可；如果你要把命令固化到脚本或平台里，则继续读配置与部署；如果你准备深入内部实现，请把这里当作前置上下文，再转入[`开发者文档`](../dev/)。
