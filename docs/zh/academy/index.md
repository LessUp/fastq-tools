# 学院

学院页回答的是“接下来该先读什么”。它不重复所有细节，而是把中文文档整理成一条可以连续阅读的学习路径：先跑通第一次使用，再理解命令与配置，最后进入维护与架构深水区。

## 学习路径

- 第一次上手：[`快速开始`](../guide/getting-started)
- 命令与工作流：[`CLI 参考`](../guide/cli-reference)
- 工程维护：[`开发者文档`](../dev/)

## 推荐阅读顺序

1. 如果你正在判断项目是否适合当前任务，先读[`导读`](../orientation/)与[`技术白皮书`](../whitepaper/)。
2. 如果你已经准备执行命令，进入[`学习指南`](../guide/)并完成[`快速开始`](../guide/getting-started)。
3. 当你需要稳定运行、自动化或调参时，继续阅读[`配置说明`](../guide/configuration)与[`部署指南`](../guide/deployment)。
4. 当你要扩展、排障或提交补丁时，再进入[`开发者文档`](../dev/)与[`参考导航`](../reference/)。

## 学院的边界

- 学院侧重“如何学会使用与维护”。
- 参考侧重“到哪里查具体接口与命令”。
- 研究附录侧重“为什么这些设计成立、还能往哪里走”。

如果你希望直接跳到资料索引，请前往[`参考导航`](../reference/)；如果你想了解资料背后的背景与外部文献，请继续阅读[`研究附录`](../research/)。
