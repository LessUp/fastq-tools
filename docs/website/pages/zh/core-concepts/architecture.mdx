# 架构

FastQTools 围绕三个核心原则设计：**零拷贝处理**、**并行流水线执行**和**规范驱动开发**。

## 零拷贝设计

所有记录处理使用 `std::string_view` 避免不必要的分配：

```cpp
for (auto record : fq::io::Reader("reads.fastq")) {
  std::string_view header = record.header();
  std::string_view sequence = record.sequence();
  std::string_view quality = record.quality();
  // 无拷贝处理
}
```

此设计最小化：
- 内存分配
- 缺页中断
- 缓存未命中

---

## 并行流水线

FastQTools 使用 Intel oneTBB `tbb::parallel_pipeline` 实现无锁并行：

```
[输入阶段] → [过滤阶段] → [处理阶段] → [输出阶段]
     ↓           ↓            ↓           ↓
   串行        并行         并行        串行
```

流水线自动扩展到可用核心，阶段间空闲开销最小。

---

## 模块结构

| 模块 | 用途 |
|------|------|
| `fq::io` | FASTQ I/O，批处理与零拷贝记录视图 |
| `fq::processing` | 过滤、修剪和并行流水线 |
| `fq::statistics` | 统计计算逻辑 |

---

## 规范驱动

每个 API 决策和文件格式都在版本控制规范中文档化：

- `openspec/baseline/api/` — API 契约
- `openspec/baseline/architecture/` — 架构决策
- `openspec/baseline/schemas/` — 数据模式

这确保：
- 无隐藏行为
- 易于审计和扩展
- 可预测的集成
