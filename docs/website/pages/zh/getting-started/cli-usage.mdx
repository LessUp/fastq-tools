# CLI 使用

FastQTools 完整命令行参考。

## `stat` — 统计分析

一遍流式处理计算 FASTQ 文件统计信息。

```bash
FastQTools stat -i <输入> [-o <输出>] [选项]
```

### 选项

| 选项 | 描述 | 默认值 |
|------|------|--------|
| `-i, --input` | 输入 FASTQ 文件（必需） | - |
| `-o, --output` | 统计输出文件 | stdout |
| `--threads` | 线程数 | 自动 |
| `--sidecar` | 生成 QC sidecar 文件 | false |

### 输出字段

- 总读段数
- 最大读长
- 总碱基数
- 碱基组成（A/T/C/G/N）
- GC 含量百分比
- Q20/Q30 百分比
- 位置质量摘要

## `filter` — 质量过滤

基于质量、长度和 N 比例阈值过滤和修剪读段。

```bash
FastQTools filter -i <输入> -o <输出> [选项]
```

### 选项

| 选项 | 描述 | 默认值 |
|------|------|--------|
| `-i, --input` | 输入 FASTQ 文件（必需） | - |
| `-o, --output` | 输出 FASTQ 文件（必需） | - |
| `--min-quality` | 最小平均质量 | 0 |
| `--min-length` | 最小读长 | 1 |
| `--max-n-ratio` | 最大 N 比例 | 1.0 |
| `--trim-quality` | 修剪质量阈值 | 0 |
| `--trim-mode` | 修剪模式：both, left, right | both |
| `--threads` | 线程数 | 自动 |

### 示例

```bash
FastQTools filter -i reads.fastq -o filtered.fastq \
  --min-quality 20 \
  --min-length 50 \
  --max-n-ratio 0.1 \
  --trim-quality 20 \
  --trim-mode both
```
