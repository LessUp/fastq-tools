# 统计

FASTQ 数据的统计计算。

## Collector

```cpp
#include <fqtools/statistics.hpp>

fq::statistics::Collector stats;

for (auto record : reader) {
  stats.add_record(record);
}

// 获取结果
size_t count = stats.read_count();
size_t bases = stats.total_bases();
double gc = stats.gc_content();
double q20 = stats.q20_percentage();
double q30 = stats.q30_percentage();
```

---

## 可用指标

| 指标 | 方法 | 描述 |
|------|------|------|
| 读段数 | `read_count()` | 总读段数 |
| 最大长度 | `max_length()` | 最大读长 |
| 总碱基数 | `total_bases()` | 总碱基数 |
| GC 含量 | `gc_content()` | GC 百分比 |
| Q20 | `q20_percentage()` | % 碱基 ≥ Q20 |
| Q30 | `q30_percentage()` | % 碱基 ≥ Q30 |
| 碱基组成 | `base_comp()` | A/T/C/G/N 计数 |

## 位置质量

```cpp
auto quality_profile = stats.quality_profile();
for (size_t i = 0; i < quality_profile.size(); ++i) {
  std::cout << "位置 " << i << ": " << quality_profile[i] << '\n';
}
```
