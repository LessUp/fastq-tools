# 构建指南

FastQTools 详细构建说明。

## 前置条件

- GCC 11+ 或 Clang 18+
- CMake 3.28+
- Ninja 构建系统
- Conan 2.x 包管理器

---

## 快速构建

```bash
# 默认构建（Clang + Release）
./scripts/core/build

# 开发模式
./scripts/core/build --dev

# 指定编译器
./scripts/core/build --compiler gcc --type Release
```

---

## 构建选项

| 选项 | 描述 |
|------|------|
| `--dev` | Debug 构建，详细输出 |
| `--compiler [gcc|clang]` | 选择编译器 |
| `--type [Debug|Release]` | 构建类型 |
| `--clean` | 先清理构建目录 |

---

## 构建输出

构建产物位于 `build/[preset]/`：

- `build/clang-release/FastQTools` - Release 可执行文件
- `build/clang-debug/FastQTools` - Debug 可执行文件

---

## 运行测试

```bash
# 所有测试
./scripts/core/test

# 仅单元测试
./scripts/core/test --unit

# 集成测试
./scripts/core/test --integration
```
