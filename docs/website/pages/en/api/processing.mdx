# Processing

Filter and trim operations for FASTQ records.

## Filter

```cpp
#include <fqtools/processing.hpp>

fq::processing::Filter filter;
filter.set_min_quality(20);
filter.set_min_length(50);
filter.set_max_n_ratio(0.1);

bool passes = filter.check(record);
```

---

## Trimmer

```cpp
#include <fqtools/processing.hpp>

fq::processing::Trimmer trimmer;
trimmer.set_quality_threshold(20);
trimmer.set_mode(fq::processing::TrimMode::Both);

auto trimmed = trimmer.trim(record);
```

---

## Pipeline

Combine operations in a parallel pipeline:

```cpp
#include <fqtools/processing.hpp>

fq::processing::Pipeline pipeline;
pipeline.add_filter(filter);
pipeline.add_trimmer(trimmer);
pipeline.set_threads(8);

pipeline.run(input_reader, output_writer);
```
