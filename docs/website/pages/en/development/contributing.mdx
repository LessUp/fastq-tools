# Contributing

We welcome contributions to FastQTools!

## Development Setup

```bash
# Clone the repository
git clone https://github.com/LessUp/fastq-tools.git
cd fastq-tools

# Install dependencies
./scripts/core/install-deps

# Build
./scripts/core/build --dev

# Run tests
./scripts/core/test
```

---

## Code Style

- C++23 standard
- Follow `.clang-format` and `.clang-tidy` configurations
- Run `./scripts/core/lint format` before committing

---

## Pull Request Process

1. Create a feature branch from `master`
2. Make your changes
3. Run tests: `./scripts/core/test`
4. Run linting: `./scripts/core/lint check`
5. Submit a pull request
