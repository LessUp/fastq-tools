# Build Guide

Detailed build instructions for FastQTools.

## Prerequisites

- GCC 11+ or Clang 18+
- CMake 3.28+
- Ninja build system
- Conan 2.x package manager

---

## Quick Build

```bash
# Default build (Clang + Release)
./scripts/core/build

# Development mode
./scripts/core/build --dev

# Specify compiler
./scripts/core/build --compiler gcc --type Release
```

---

## Build Options

| Option | Description |
|--------|-------------|
| `--dev` | Debug build with verbose output |
| `--compiler [gcc|clang]` | Select compiler |
| `--type [Debug|Release]` | Build type |
| `--clean` | Clean build directory first |

---

## Build Output

Build artifacts are placed in `build/[preset]/`:

- `build/clang-release/FastQTools` - Release executable
- `build/clang-debug/FastQTools` - Debug executable

---

## Running Tests

```bash
# All tests
./scripts/core/test

# Unit tests only
./scripts/core/test --unit

# Integration tests
./scripts/core/test --integration
```
